# Security Policy

## Reporting a Vulnerability

Please report security vulnerabilities privately through GitHub Security Advisories:

- https://github.com/rgonek/jira-adf-converter/security/advisories/new

If you cannot use advisories, open a private channel with the maintainer before disclosing details publicly.

Please include:

- A clear description of the issue and potential impact.
- A minimal reproduction input (`.json` / `.md`) when possible.
- Affected version(s) or commit SHA.
- Any known mitigations or workarounds.

## Response Expectations

- Initial acknowledgment target: within 3 business days.
- Triage target: within 7 business days.
- Fix timelines depend on severity and release risk.

## Disclosure Process

1. We acknowledge and triage the report.
2. We prepare and test a fix.
3. We release a patched version and publish notes.
4. We coordinate disclosure timing with the reporter.

## Supported Versions

Security fixes are prioritized for the latest released version and `main`.
